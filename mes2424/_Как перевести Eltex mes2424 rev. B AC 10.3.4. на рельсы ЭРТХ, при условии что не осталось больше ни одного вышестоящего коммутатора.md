// КАК ПЕРЕВЕСТИ Eltex mes2424 rev. B AC 10.3.4 на рельсы ЭРТХ, при условии что не осталось больше ни одного вышестоящего коммутатора?  

1) Cоздаём пустой VLAN 99:  

conf t  
vlan 99  
name MGMT  
vlan active  
exit  

2) Теперь вешаем на него IP-шник:  

conf t  
interface vlan 99  
description MGMT  
ip address 10.245.151.xx 255.255.255.192 (/26 маска в нашем случае просто для примера)  
no ipv6 enable  
no shutdown  
exit  

3) Вот теперь заходим на какой-нибудь вышестоящий коммутатор, например, 10.245.151.25 через Putty!  
Если мы попали на D-Link и там (якобы) не работает telnet - врубаем команду enable admin, или admin enable и telnet заработает.  
Если затребует пароль - просто Enter.  

telnet 10.245.151.xx (ip-шник нашего последнего Eltex-a)  
Вводим от него логопас (пока Радиус не настроен - это будет обычный админ/пароль)  
show ip route (смотрим дефолтные маршруты, маршрут будет старый. Пока его не сносим !!!)  

Прописываем ВТОРОЙ МАРШРУТ С ПЕРВОЙ ДЕФОЛТНОЙ МЕТРИКОЙ. Метрику можно не указывать, он поставит её сам!  

conf t  
ip route 0.0.0.0 0.0.0.0 10.245.151.62  
Жмахаем Enter!  

После этого, у нас получится примерно вот такое уродство:  

S 0.0.0.0/0  [1/1] via 10.140.79.1	<--- Старый дефолтный маршрут.  
             [1/1] via 10.245.151.62	<--- Новый дефолтный маршрут. Так быть не может, один надо убрать. Мы это сделали, чтобы нас не выкинуло из сессии.  
C 10.140.79.0/24 is directly connected, vlan 1850  
C 10.245.151.0/26 is directly connected, vlan 99  

4) Удаляем старый маршрут:  

conf t  
no ip route 0.0.0.0 0.0.0.0 10.140.79.1  
exit  
show ip route <--- Проверяем, что в роутах.  

5) Если всё хокейно - сохраняемся командой copy running-config startup-config  
Там должен быть один маршрут, прописанный статикой с метрикой 1.  
Всё должно выглядеть вот так:  

Vrf Name:          default  
---------  
S 0.0.0.0/0  [1/1] via 10.245.151.62  
C 10.140.79.0/24 is directly connected, vlan 1850  
C 10.245.151.0/26 is directly connected, vlan 99
