Прошивка: 10.3.4  

1. Заходим с вышестоящего коммутатора из той же подсети.  
1.1 Подключаемся telnet-ом к Eltex-у.  

2. Смотрим текущий шлюз: show ip route  
3. Удаляем маршрут no ip route 0.0.0.0 0.0.0.0 [ip-адрес шлюза]  
4. Создаём новый gateway:  

ip route 0.0.0.0 0.0.0.0 10.245.151.62  

5.  

interface vlan 99  
description MGMT  
ip address 10.245.151.xx 255.255.255.192  
no ipv6 enable  
no shutdown  
exit  

6. Теперь заходим через PUTTY по новому IP.  
И настраиваем SNTP.  

sntp  
 set sntp client enabled  
 set sntp client addressing-mode unicast  
 set sntp unicast-poll-interval 16384  
 set sntp unicast-server ipv4 10.6.37.21 priority 1  
 set sntp unicast-server ipv4 10.6.36.38 priority 2  
exit  
clock time source ntp  
clock utc-offset +07:00  

7. Теперь настроим РАДИУС.  

aaa authentication default radius local // <-- Чтобы можно было заходить и под Радиус учёткой, и под локальным админом.  
radius-server host 10.6.39.1 auth-port 2030 acct-port 2050 key "здесь пишем ключ" primary  
radius-server host 10.6.39.162 auth-port 2030 acct-port 2050 key "и здесь ещё раз пишем тот же самый ключ"  

8. Теперь открываем ещё одно окно PUTTY, не закрывая старое и пробуем зайти под РАДИУС-УЧЁТКОЙ.  
Как только зайдём - вбиваем вот такую команду:  

[LLDP]  

set lldp enable  
set lldp version v2  

  lldp tlv-select basic-tlv port-descr  
  lldp tlv-select basic-tlv sys-name  
  lldp tlv-select basic-tlv sys-descr  
  lldp tlv-select basic-tlv sys-capab  
  lldp tlv-select basic-tlv mgmt-addr ipv4 10.245.151.43  
  lldp tlv-select dot1tlv port-vlan-id  
  lldp tlv-select dot1tlv mgmt-vid
